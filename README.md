# SQLust

**SQLust** — компактный настольный клиент MySQL и PostgreSQL для Windows и Linux.

Независимые вкладки таблиц и SQL, разделение рабочего пространства, редактирование данных и структуры, SSH-туннели и светлая/тёмная тема.

## Загрузка

Готовые сборки находятся в [Releases](https://github.com/YMongoose/sqlust-releases/releases).

- Windows x64: `sqlust-windows-x86_64.exe`. Сохраните как `sqlust.exe` в доступную для записи папку и запустите.
- Сборки Linux будут добавляться по мере доступности. Для готового бинарного файла выдайте право запуска: `chmod +x sqlust-linux-x86_64`.

## Обновления

В SQLust откройте **Настройки → Обновления**. Программа проверяет цифровую подпись Ed25519 и SHA-256 пакета. Загрузка и перезапуск выполняются по вашему выбору. Подключения и настройки сохраняются.

`update-manifest.json` и `update-manifest.sig` — служебные файлы обновления, вручную их запускать не нужно.
